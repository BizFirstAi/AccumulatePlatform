# AccumulatePlatform
**Live site:** https://accumulateplatform.bizfirstai.com

Marketing, guide, and reference site for AccumulatePlatform — the blockchain API layer
(284 endpoints, 32 domains) behind the BizFirstAi ecosystem. The API itself
(accumulateplatform.com) is headless and has no UI of its own; this repo is that UI.

- `docs/index.html` — landing page
- `docs/get-started.html` — API guide (base URL, wallet-signature auth flow, first request)
- `docs/api-reference.html` — full searchable endpoint reference, generated from the live OpenAPI spec

Site content is served from the [`/docs`](./docs) folder via GitHub Pages.
