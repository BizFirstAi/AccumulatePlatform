Getting Started

Everything you need to make your first call to AccumulatePlatform — base URL, authentication, and a working example.

01Base URL

Every endpoint hangs off a single host. There's no versioned subdomain or region to pick — one host, one ledger.

https://accumulateplatform.com

Most paths additionally include a version segment, /api/v1/, though a handful of legacy discovery routes sit at the root. The reference page shows the exact path for every endpoint.

02Public vs. signed calls

AccumulatePlatform doesn't use API keys. Instead, calls fall into two groups:

  • Public reads — lookups, name translations, product listings, DID resolution. No credentials required; just call the endpoint.
  • Signed writes — anything that registers, sends, or mutates on-chain state (sending an AI message, verifying a token, saving a business network). These require a wallet signature attached to the request body.
How to tell which is which: if the request schema wraps its payload in an authRequest object, it's a signed call. The reference page flags this per endpoint where it's declared in the spec.

03Wallet signature auth

Signed calls follow a three-step nonce-and-sign pattern, the same one used across the wider Accumulate network:

  1. Request a nonce for your address 
    GET /api/v1/TokenGateway/getNonce/{address}/{messageId}
  2. Sign the returned message locally

    Sign it with the private key for address — this never touches the network. You now have a signature.

  3. Attach it to your call

    Include the signed payload as authRequest in the body of the endpoint you're calling:

    {
  // wraps every signed request
  "authRequest": {
    "address": "acc://your-identity.acme",
    "signature": "<signature from step 2>",
    "authMessage": {
      "nonce": "<nonce from step 1>",
      "timeStamp": 1732900000,
      "message": "<message that was signed>"
    }
  },
  // endpoint-specific fields go alongside authRequest
  "Info": { "...": "..." }
}
Response bodies aren't formally typed in the published spec beyond a 200 OK. Use Swagger's "Try it out" against a real address to see the live shape before you build against it.

04Your first request

Start with a public read — no signing required. This resolves a Qoboto social profile field for an identity:

GET https://accumulateplatform.com/api/v1/Id/ProfileFullName?Identity=acc://example.acme

Or as curl:

curl "https://accumulateplatform.com/api/v1/Id/ProfileFullName?Identity=acc://example.acme"

Swap the identity for one you know exists to see real data come back.
