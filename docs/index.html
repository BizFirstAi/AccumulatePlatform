Authentication

Wallet-signed, not API keys

Sensitive writes are authenticated by signing a nonce with your wallet — the same pattern used across the Accumulate network. Public reads (lookups, translations, listings) don't require it.

Request a nonce

Get a message to sign

GET /api/v1/TokenGateway/getNonce/{address}/{messageId}

Sign it

Sign with your wallet

Sign the returned message locally with the private key for address. Nothing is sent yet.

Attach & call

Send address + signature

Include { address, signature, authMessage } as authRequest on the call you're authenticating.
